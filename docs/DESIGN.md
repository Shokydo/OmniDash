# Дизайн OmniDash

Тёмная панель «obsidian + aurora»: почти чёрный фон, холодный сине-фиолетовый акцент, плотные таблицы и моноширинные детали. Наследует язык OmniPanel, но с акцентом на данные серверов, а не на список процессов.

## Принципы

1. **Данные важнее декора.** Никаких иллюстраций на рабочих экранах: графики, цифры, статусы, строки.
2. **Плотно, но дышит.** Карточки 14 px радиуса, 14–18 px паддинги, границы из полупрозрачных линий вместо теней.
3. **Цвет — сигнал.** Акцент ведёт действие, зелёный/янтарный/красный означают состояние, а не украшают.
4. **Моноширинный для фактов.** Порты, ID, версии, пути, команды, размеры — всегда mono.
5. **Живость без шума.** SSE-обновления приходят мягко: цифры меняются, тост появляется в углу, скелетоны не мигают.
6. **Один экран — одна задача.** Страница сервера не пытается показать всё сразу: восемь вкладок.

## Токены

```css
--bg: #06070a;           /* фон */
--surface: #0c0f15;      /* карточка */
--surface-2: #11151e;    /* вложенный блок */
--line: rgba(255,255,255,.07);
--text: #e9ecf4;
--text-dim: #9aa3b6;
--text-mute: #646d81;
--accent: #7c8cff;       /* aurora */
--green: #4ade80;  --amber: #fbbf24;  --rose: #fb7185;
--sky: #38bdf8;    --violet: #c084fc;
--radius: 14px; --radius-sm: 10px; --radius-lg: 20px;
--mono: ui-monospace, "SF Mono", "JetBrains Mono", …;
--sans: -apple-system, "Segoe UI", Inter, …;
--sidebar: 250px;
```

Фон — базовый цвет плюс два радиальных свечения: акцентное сверху справа и едва заметное зелёное снизу слева. Они дают глубину без картинок.

Акцент можно менять в настройках (`--accent` и `--accent-rgb`), интерфейс перекрашивается целиком.

## Типографика

| Роль | Размер / вес | Где |
|---|---|---|
| H1 страницы | 26–30 px / 680 | заголовок страницы |
| Заголовок карточки | 14 px / 600 | `panel-title` |
| Основной текст | 14 px / 400 | интерфейс |
| Мелкий | 12 px / 400 | подписи, `tiny dim` |
| Метка-капс | 10–11 px / 600 + tracking | `eyebrow`, `label` |
| Цифры | 30–34 px / 680, `-0.03em` | стат-карточки |
| Моно | 11–13 px | порты, ID, версии, консоль |

Сглаживание включено, межстрочный 1.5. Заголовки не используют декоративные шрифты — только системный стек.

## Сетка и плотность

- Сайдбар 250 px, основная область — `minmax(0,1fr)`.
- Контент ограничен по ширине на больших экранах, чтобы строки не растягивались.
- Карточки: `grid` с `gap: 14–16px`; на планшете 2 колонки, на телефоне 1.
- Стат-карточки: 4 в ряд → 2 → 1.
- Таблицы: 40–44 px высота строки, левый акцент при наведении, моноширинные числа.

## Компоненты

- **Кнопки** `btn`, `btn primary`, `btn ghost`, `btn sm`, `btn danger`. Радиус 10 px, фокус-кольцо акцента, disabled — прозрачность .45.
- **Статус-пилюли** `pill` с точкой: running (зелёная, пульс), offline (серая), suspended (янтарная), error (красная).
- **Карточки** `card` с `card-head` и `card-body`; заголовок с иконкой 15 px.
- **KV-списки** `dl.kv` — пары «параметр → значение», значения справа, mono для чисел.
- **Консоль** `term` — чёрный фон, ANSI-классы, моно, мягкий скролл, поле ввода с `>`.
- **Графики** SVG, акцентная линия и заливка-градиент, без сетки, с подсказкой при наведении.
- **Модалки** оверлей `rgba(3,4,8,.65)` + блюр, карточка 20 px, закрытие по Esc/клику.
- **Тосты** справа сверху, три типа, авто-скрытие, стек.
- **Палитра ⌘K** — список команд с группами и подсказками, поиск по подстроке, Enter — выполнить.
- **Пустые состояния** `empty` — иконка, заголовок, короткое объяснение и действие.
- **Скелетоны** — прямоугольники с мягким переливом, без резких вспышек.

## Движение

- Переходы 120–180 ms, `ease-out`.
- Появление модалки — масштаб 0.98 → 1 и прозрачность.
- Пульс только у активного статуса и только точкой.
- Графики обновляются без анимации перерисовки, чтобы цифры не «прыгали».
- `prefers-reduced-motion` отключает пульс и переходы.

## Адаптив

| Ширина | Поведение |
|---|---|
| ≥ 1200 | сайдбар, 4 стат-карточки, две колонки в сложных блоках |
| 900–1199 | сайдбар сжимается, 2 колонки |
| < 900 | сайдбар прячется за кнопку, навигация в шторке, карточки в одну колонку, таблицы скроллятся, консоль на всю ширину |

На телефоне логин показывает компактный бренд над формой; арт-панель скрывается.

## Доступность

- Фокус виден всегда: 2 px кольцо акцента.
- Кликабельные зоны ≥ 36 px; иконки-кнопки имеют `aria-label` и `title`.
- Контраст основного текста к фону ≥ 7:1, вторичного ≥ 4.5:1.
- Статус не передаётся только цветом: есть текст и точка.
- Модалки закрываются Esc, фокус возвращается на инициатора.
- `⌘K` дублируется кнопкой поиска в шапке.

## Отличия от OmniPanel

| OmniPanel | OmniDash |
|---|---|
| акцент на процессах и TPS | акцент на серверах, доступах, сроках |
| одна длинная страница | страница сервера с восемью вкладками |
| локальный десктоп | веб-панель с ролями и мультипользовательностью |
| обновления с GitHub | локальный канал без GitHub |
| светлая тема как опция | только тёмная, акцент настраивается |
