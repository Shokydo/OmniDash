# Запуск OmniDash на Windows (батник)

Батник `start.bat` запускает панель локально — можно посмотреть оформление и функционал без Docker и без сборки. При первом запуске он сам выполнит `npm install` (нужен только `ssh2` для SFTP).

## Быстрый старт

1. Установите **Node.js LTS ≥ 18.17** с https://nodejs.org (при установке оставьте галочку *Automatically install the necessary tools*).
2. Склонируйте репозиторий или скачайте ZIP:
   ```bat
   git clone https://github.com/Shokydo/OmniDash.git
   cd OmniDash
   ```
3. Дважды кликните по **`start.bat`** (или запустите из командной строки).
4. В меню выберите **[1] Запустить панель**.
5. Браузер откроется сам на **http://localhost:7777**. Если не открылся — введите адрес вручную.

Первый запуск сам создаст папку `data/` и демо-данные: 6 серверов, 4 пользователя, 2 узла, 17 портов, 4 шаблона.

## Логины по умолчанию

| Логин | Пароль | Роль | Что видно |
|---|---|---|---|
| `admin` | `omnidash` | администратор | всё: люди, узлы, порты, шаблоны, журнал, настройки, обновления |
| `steve` | `steve123` | пользователь | 3 своих сервера, лимиты 8 ГБ / 300% / 40 ГБ, запрос продления |
| `mira` | `mira123` | пользователь | 2 сервера, включая python-бота |
| `kotik` | `kotik123` | пользователь | сервер с истёкшим сроком — видно авто-приостановку |

## Что посмотреть за три минуты

1. Войти админом → **«Обзор»**: карточки нагрузки, лента событий, блок «Требуют внимания».
2. **«Серверы» → «Мир Друзей» → «Консоль»** → запустить, ввести `say привет`, увидеть ответ в логе.
3. **«Файлы»** → открыть `server.properties` → поменять `motd` → сохранить.
4. **«Бэкапы»** → создать копию → скачать ZIP.
5. **«Доступы»** → выдать `mira` право «Консоль», выйти и войти под `mira`.
6. Админом: **«Пользователи»** → лимиты и блокировка; **«Узлы»** → порты; **«Обновления»** → проверка.
7. Нажать `Ctrl+K` — палитра команд.

## Режимы батника

| Команда | Что делает |
|---|---|
| `start.bat` | меню: обычный запуск / dev / другой порт / сброс / проверка |
| `start.bat 7777` | запустить сразу на порту 7777 |
| `start.bat 8080` | запустить на порту 8080 |
| `start.bat dev` | dev-режим: автоперезапуск при правках `server.js`/`core/` + автоперезагрузка вкладок |
| `start.bat dev 7778` | dev-режим на порту 7778 |
| `start.bat reset` | сбросить демо-данные (`data` → `data-backup-ДАТА`) и запустить |
| `start.bat --help` | справка |
| `start-dev.bat` | ярлык на dev-режим |

Остановка — `Ctrl+C` в окне батника. Данные сохраняются в `data/` (база `db.json`, серверы, бэкапы, логи).

## Что проверяет батник перед запуском

- **Node.js** — есть ли в `PATH`, версия ≥ 18.17. Если нет — откроет страницу загрузки.
- **Файлы проекта** — `server.js`, `public/index.html`, `package.json` рядом с батником.
- **Порт** — свободен ли 7777. Если занят — предложит другой.
- **Python** — только предупреждение: нужен для демо-сервера *Price Parser* (шаблон запускает `python3`, на Windows обычно это `python`). Остальные демо-серверы работают без Python.
- **npm** — нужен один раз для `ssh2` (SFTP); батник ставит автоматически, если `node_modules` нет.

## Нюансы Windows (честно)

- **Метрики CPU/RAM демо-серверов на Windows будут нулевыми.** Демон читает статистику из `/proc` (Linux), на Windows `/proc` нет — графики останутся плоскими. Консоль, файлы, бэкапы, доступы, порты, сроки, расписание — всё работает. Для точных метрик запускайте панель в **WSL2** или на Linux.
- **Price Parser (python-бот) на Windows не стартует** без алиаса `python3`. Лечение: установите Python с https://www.python.org и добавьте алиас, либо поменяйте стартовую команду шаблона в админке на `python -u ...`.
- **Брандмауэр Windows** может спросить про `node.exe` при первом запуске — разрешите для частных сетей.
- **Кодировка:** батник использует `chcp 65001` (UTF-8), кириллица в меню отображается корректно на Windows 10/11. Если символы всё же «кракозябры» — откройте батник в Блокноте и сохраните как UTF-8, либо просто игнорируйте — на запуск это не влияет.
- **Путь без пробелов** — лучше держать репозиторий в пути без пробелов и кириллицы (например `C:\OmniDash`), хотя батник использует кавычки и в большинстве случаев работает и с пробелами.

## Сброс демо-данных

Если что-то сломали в интерфейсе: остановите панель (`Ctrl+C`), запустите `start.bat reset` — старая `data/` переименуется в `data-backup-ДАТА`, демо пересоздадутся. Или вручную удалите папку `data/` и запустите снова.

## Linux / macOS

Аналог батника — `start.sh`:
```bash
chmod +x start.sh
./start.sh          # порт 7777
./start.sh 8080     # порт 8080
./start.sh dev      # dev-режим
./start.sh reset    # сброс демо
```
